Proyecto: Portal Web de Gestión para Consultorio Odontológico "Mariadent"
Descripción del proyecto
El proyecto consiste en el desarrollo de un portal web básico y funcional para el consultorio odontológico "Mariadent", ubicado en la zona de Villa Alemania, calle 2 Blasco Núñez de Vela. El objetivo principal es digitalizar y optimizar la gestión de pacientes, permitiendo llevar un registro ordenado de los mismos y sus atenciones, reemplazando los métodos manuales (papel o Excel) por una base de datos centralizada y accesible.
Objetivos del Proyecto

Objetivo General:
Crear un sistema web que permita registrar, almacenar y consultar la información de los pacientes y sus citas de manera eficiente y segura.

Objetivos Específicos:
* Diseñar una interfaz web sencilla e intuitiva para el personal del consultorio.
* Implementar una base de datos relacional para almacenar la información de los pacientes y el historial de citas.
* Permitir la búsqueda rápida de pacientes por nombre o cédula de identidad.
* Establecer un módulo básico para agendar y visualizar citas.
